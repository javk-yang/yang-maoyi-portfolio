# 杨茂意作品集

页面已按 AI 项目、影像创作、摄影作品三个章节重新设计。

直接双击 `index.html` 即可打开。若浏览器限制本地视频播放，可在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

联系区已填写公开邮箱和微信号。整个文件夹可直接发布到 GitHub Pages。

## GitHub Pages 发布

1. 登录 GitHub，创建一个公开仓库，例如 `yang-maoyi-portfolio`。
2. 把本目录中的所有文件（包括 `.nojekyll` 和 `assets` 文件夹）上传到仓库根目录。
3. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
4. 等待部署完成，在 Pages 设置页获取公开链接。一般形式为 `https://用户名.github.io/yang-maoyi-portfolio/`。

页面文件总计约 87 MB；请保留仓库及 GitHub Pages 设置，公开链接才能持续访问。发布后的修改需要再次提交到仓库。GitHub Pages 是静态托管，页面内上传的作品只保存在上传者自己的浏览器，不会自动发布给访客。

## 作品管理

点击页面右上角的“管理作品”，可以：

- 向 AI 项目、影像创作、摄影作品板块添加图片或视频作品
- 开启管理模式，编辑或删除自定义作品，也可隐藏默认作品
- 恢复被隐藏的默认作品
- 导出和导入作品备份（包含默认作品的隐藏状态）

编辑自定义作品时可以直接修改标题、介绍、类型、标签和板块；不重新选择文件会保留原图片或视频。三个重点 AI 项目可点击封面进入案例详情。

新增作品使用浏览器 IndexedDB 保存，仅在当前浏览器中有效。此版本沿用此前的数据库名称和作品 ID，已有上传与默认作品隐藏状态会继续读取。若需要多设备同步或多人管理，需要部署带数据库和文件存储的后台服务。
